# TSB Bot — v0.8.0

Бот для основного места The Strongest Battlegrounds, PlaceId `10449761463`.
Выбирает ближайшего видимого живого игрока или Weakest Dummy, подходит,
разворачивается и атакует. Для обычного Сайтамы включён выбор способностей по КД.

## Запуск в Xeno

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/TSB-Bot/687962c220445d3f203684c9c65d4ce6a91b2b42/main.lua"))()
```

Дождитесь появления персонажа, выполните загрузчик и вернитесь в окно Roblox.
Бот, умения и подтверждение ЛКМ включены по умолчанию. Держите курсор над сценой.
Повторный запуск выгружает предыдущую копию. Ссылка закреплена на версии 0.8.0.

## Выбор способностей

Для обычного Сайтамы (`Character.Character = Bald`) проверяются названия
всех четырёх Tool и соответствие подписей кнопок стандартной раскладке:

| Кнопка | Умение | Когда выбирается |
| --- | --- | --- |
| 2 | Consecutive Punches | Первый приоритет среди обычных атак |
| 3 | Shove | Если 2 недоступна |
| 1 | Normal Punch | Если 2 и 3 недоступны |
| 4 | Uppercut | Первый приоритет для лежащей цели, если готова |

На стоящую цель 4 не расходуется. Если подходящих готовых умений нет, работает M1.
После каждого применения и короткой паузы на анимацию приоритет проверяется заново.
Например: 2 в КД → 3; если к следующему выбору 2 готова, бот снова выбирает 2.
Фиксированные интервалы КД 12–14 секунд и прежние жёсткие цепочки убраны.

КД читается из **живой панели**:
`PlayerGui.Hotbar.Backpack.Hotbar.<1–4>.Base.Cooldown`.
В пользовательском снимке активный индикатор способности 2 имел отрицательную
высоту `Y.Scale = -0.776453793`. Проверяется модуль высоты, включая пиксельное
смещение. Отсутствующий индикатор в существующей проверенной кнопке или нулевая
высота означают готовность. `Tool.Enabled=false` дополнительно запрещает ввод,
но `Enabled=true` само по себе не подтверждает окончание КД.
Шаблон `Backpack.LocalScript.Cooldown` игнорируется.

Если панель отсутствует, подпись умения не совпадает или геометрия некорректна,
готовность неизвестна: эта кнопка пропускается. GUI показывает `готов`, `КД` или `?`.
Точное число секунд не вычисляется: полная длительность из снимка неизвестна.

Лежащая цель определяется по флагам Ragdoll/Ragdolled/Downed, состоянию Humanoid
или горизонтальному положению туловища; дополнительно проверяется близость земли.
Обычный прыжок не считается падением. Работает для игроков и Weakest Dummy.
Распознавание падения и задержки после умений требуют проверки в живой игре.

## GUI и управление

| Управление | Действие |
| --- | --- |
| F6 / кнопка бота | Пауза и продолжение |
| F7 / «Отчёт» | Диагностика в консоли и буфере, если setclipboard доступен |
| F8 / «Умения Сайтамы» | Включить/выключить автоматические умения |
| F9 | Цифра + ЛКМ либо только цифра |
| F10 | Игроки + манекен → только манекен → только игроки |
| End / X | Полная выгрузка |

Окно перетаскивается за заголовок и переживает возрождение. Наведение на панель,
перетаскивание, чат и потеря фокуса приостанавливают управление и отпускают ввод.
Отчёт F7 содержит источник и высоту каждого индикатора, состояние лежащей цели,
последнюю попытку умения и отдельные счётчики отправленных/полученных клавиш.

Цифры отправляются только через подтверждённый пользователем
`VirtualInputManager:SendKeyEvent`. Подтверждающий ЛКМ разрешён после получения
ожидаемой цифры в `UserInputService.InputBegan`. Нет события за 0,4 секунды — режим
умений останавливается с диагностикой. Другие клавиатурные способы не используются.
M1 использует `mouse1press/mouse1release`, запасной способ мыши — Roblox VirtualInput.
Полученная клавиша ещё не подтверждает принятие умения сервером или попадание.

## Ограничения

Автоматические умения поддерживают обычного Сайтаму со стандартными кнопками 1–4.
Для остальных бойцов остаётся M1. Ульта, блок, рывки и поиск пути не реализованы.
Дистанции: поиск до 80 studs, удержание цели до 110, остановка в 3,5, M1 до 5.
ForceField, препятствия, смерть и большая разница высоты исключают цель.
Все игровые ограничения на урон, stun и КД сохраняются.

## Проверка

Основной файл скомпилирован официальным Luau 0.743. Выполнено 102 локальных
проверки с имитацией Roblox: ввод и его отмена, GUI, смена бойца, цели и NPC,
отрицательная/нулевая высота КД, неизвестная панель, исключение шаблона,
пересоздание кнопок, выбор 2 → 3 → 1 и 4 для лежащей цели, возобновление
готового умения без фиксированного таймера. Это проверка логики; версия 0.8.0
ещё не проверена в живом клиенте TSB. Структура панели взята из отчёта пользователя.

## Диагностика cooldown с GUI

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/TSB-Bot/73c82ae0a06281421419fa2d70f94f8e024462bb/cooldown_probe.lua"))()
```

Это отдельное диагностическое окно. Поставьте бота на паузу F6, примените
умение вручную, нажмите «Снять отчёт» и «Копировать». Если буфер недоступен,
используйте «Выделить текст» и Ctrl+C. Для проверки падения снимите отчёт,
пока манекен действительно лежит. Этот загрузчик не включает боевого бота.
